# 01 · 总览：这条线做了什么

## 起点

目标：为「让大肥鱼（B 站账号）说话更像本人」建立个人评论语料库，先分析真实说话风格，再用于风格对照测试。

## 任务 01：先建最小语料

- 盘点 DSH 里可用的 B 站工具，确认能读什么、不能读什么。
- 采集用户空间动态 + 可发现评论，产出 `raw.jsonl` / `comments.csv` / `manifest.json`。
- 结论：旧版动态端点被拦（返回 HTML），改用 polymer 新版接口 + WBI 签名；评论没有“全量历史”接口，只能逐视频分页 + 按 mid 过滤。
- 首批：24 条动态、2 条评论、20 条脱敏预览。

## 任务 02：扩样本 + 补上下文

- 动态翻到 62 页 / 744 条（2023-07 → 2026-10，接口仍 `has_more`）。
- 评论扫描 24 个候选视频（18 个转发视频 + 6 个本人投稿），共 4913 条评论，命中 18 条（16 一级 + 2 二级）。
- 逐视频记录页数、总量、命中、是否完整、失败原因；断点续采。
- 补 18 个视频的标题/简介；给 2 个视频补字幕片段；其余缺失标 `context_missing`。
- 结果：762 条原始记录 / 729 条独立表达；类型覆盖转发 520、原创文字 146、原创图文 78、评论 18。

## 任务 03：对账 + 逐行标签

- 对账：`current_run_hits=14`、`previously_collected_rows_retained=2`、`cumulative_comment_l1_rows=16`、`comment_l2_rows=2`；不再混淆“本轮扫描”和“累计文件”。
- 语境口径：区分“有元数据”和“真的理解视频内容”；字幕片段只有 5 条记录 / 2 个视频。
- 标签：729 条逐行 `topic_label / expression_intent / style_mode / context_confidence / label_reason`；转发理由、引用内容、系统前缀分开存。
- 明确：标签是规则启发式首版，不是硬性人格规则。

## 任务 04：A/B 对照测试

- 选 20 个视频（游戏/动物/搞笑/音乐/剧情/知识），同一模型、同一上下文。
- A = 中性基础提示词；B = 基础 + 第一版风格指南。
- 15 组生成、5 个 SKIP（只有标题/简介无内容）；X/Y 随机盲评，不发布。
- 产出 `test_results.csv` + `blind_review.md`，等用户评分。

## 关键决策

- **评论不做“全量”承诺**：B 站没有公开的全量用户评论接口；只报告“已知视频范围内”的覆盖。
- **原始层不删**：重复文本用 `duplicate_group_id` 分组、`canonical_for_style` 选出用于分析的一条，不物理删除。
- **不把标签当人格**：标签只描述可复核文本特征；不推断政治/心理/人格。
- **不公开原始语料**：公开仓库只放方法、统计、脱敏样例与测试结果。

## 已知缺口

1. 评论覆盖受 30 页/视频上限与接口返回量限制，`complete=false` 的视频未扫全。
2. 观看历史/点赞记录是私密数据，当前授权账号无权读取；未绕过。
3. 公开收藏夹接口返回 -400，未取得收藏视频。
4. 字幕/正文只补了 2 个视频；绝大多数记录只有标题/卡片。
5. 风格标签对诗歌/引用类文本有误判，需要人工校准或更强标注。
