## 口吻特征（从语料归纳，非硬规则）

- 短句为主：大量 5–35 字的即时反应；有具体内容时才写长。
- 口语化：常用“吧 / 了 / 啊 / 就 / 其实 / 反正”；少用书面连接词。
- 具体：接住视频里的一个细节/观点，不空泛夸“内容很丰富”。
- 允许反问、吐槽、自嘲；不端着，也不喊口号。
- 转发理由与被转发标题/原文分开；系统“回复 @X :”前缀不算口癖。

## 局限

- 规则启发式首版：诗歌/引用类文本会被“因为/所以”误判成解释/论证（例如《天将降大任…》）。
- 主题依赖标题/简介关键词；无视频/无引用的转发会落到 unknown。
- `context_confidence=low` 的 361 条主要缺视频内容，不适合当“理解视频后”的范例。
- 标签只描述文本特征，**不是人格结论**；不要当硬性规则直接写进提示词。
