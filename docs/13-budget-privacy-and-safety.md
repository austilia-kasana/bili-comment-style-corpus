## 四、停止条件

### 4.1 必须停止的情况

| 条件 | 动作 |
|---|---|
| 预算耗尽 | 停止所有模型调用，报告已花费金额 |
| 权限不足 | 停止该步骤，报告需要什么权限 |
| 资料无法读取 | 停止，报告路径与错误 |
| 操作不可逆 | **停止，先请求授权** |
| 出现无限循环迹象 | 立即终止 |
| 单次运行超过预定步数 | 终止并报告进度 |

### 4.2 停止时必须记录的

```json
{
  "stopped": true,
  "reason": "具体原因，不是'出错了'",
  "at_step": "停在哪一步",
  "completed": ["已完成的产出"],
  "next_possible_actions": ["可行的后续动作，按成本排序"]
}
```

**不得为了"完成任务"而编造结果。** 宁可交付一份写明了 5 个未完成项的报告，也不要交付一份看似完整但内容是编的。

### 4.3 每次运行的边界

```
单次运行最多处理：一个阶段的一个子任务
运行结束必须落盘：产出的文件 + 本次的操作记录
运行结束必须报告：做了什么、花了多少、还剩什么
```
