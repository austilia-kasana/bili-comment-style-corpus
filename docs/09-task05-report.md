## 2. v2 改了什么

在 v1 上增加 7 条硬规则（完整见 `data/style_guide_v2.md`）：

1. 具体 ≠ 准确：不改动作/顺序/因果；简介写了 ≠ 视频演了。
2. 不推断未证实的动机：不写“故意/其实就是/真正想要”。
3. 不编造个人体验：不写“跟着哼/我玩过/我看过”。
4. 不强制金句：不每条都套“事实 + 转折 + 犀利结论”。
5. 先考虑最自然的直接反应。
6. 五个目标（像本人/贴合/有内容/不公式化/立场）不能互相替代。
7. 不足就 SKIP。
