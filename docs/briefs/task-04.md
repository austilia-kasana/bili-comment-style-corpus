# 任务 04：个人评论风格对照测试

目标：验证第一版个人风格指南是否让大肥鱼生成的 B 站评论更自然、更符合用户表达习惯。

1. 选取约 20 个视频，尽量覆盖游戏、动物、搞笑、音乐、剧情和知识类等不同场景。优先使用用户已有候选视频，避免为了测试继续大规模爬取。
2. 为每个视频准备相同的上下文：标题、简介，以及实际可获得的字幕或正文片段。明确区分已知事实与未确认的内容；上下文不足时允许 SKIP。
3. 每个视频生成两份候选：A 使用现有基础提示词；B 使用同一基础提示词并加载第一版个人风格指南。两组使用相同模型、相同上下文和相同生成参数（若可控），不允许自动发布。
4. 输出 test_results.csv，字段至少包含 video_id/url、topic、context_quality、baseline_comment、personalized_comment、skip_reason。不得把历史语料里的事实、立场或个人经历直接搬到当前视频评论里。
5. 另外生成 blind_review.md，把 A/B 候选匿名标成 X/Y 并随机化顺序，供用户评价；暂不让模型自行宣称哪一版更像真人。
6. 评估维度：像不像用户、是否贴合视频、是否有实际内容、是否公式化、是否存在事实错误或不恰当立场。允许两版都不合格，也允许两版都 SKIP。
7. 不按评论数量或字数评判质量，不连续套用同一种句式。无观点、无上下文或只有复述标题时，跳过优于硬写。
8. 只交付测试结果，不发布评论、不继续扩大采集，也不要将本轮标签直接当作硬性人格规则。
9. 注意 style_labels.csv 含有用户历史原文，其中有个人日记和敏感自述。未经必要性判断，不要继续将整份原始语料转发给额外的外部服务；优先使用精选、与当前场景相关的范例。
