# 任务 01：建立个人 B 站评论语料库

任务目标：为用户建立个人 B 站评论语料库，用于后续分析其真实说话风格。当前阶段只采集和整理，不发布任何评论。

1. 检查当前 DeepSeek Harness 可用的 B 站工具，明确每个工具可读取的内容、权限和限制。不要假设视频提取插件可以获取账号的完整历史发言。
2. 在用户授权的范围内，分别采集个人空间动态、可访问的评论记录及可补充的历史评论。先检查数据来源和覆盖范围，再决定采集方案。
3. 动态列表需要正确翻页；记录分页游标、失败原因和已完成范围，支持断点续采。遇到验证码、限流、权限拒绝时停止对应任务并报告，不尝试绕过风控。
4. 保留原始数据，不覆盖、不改写评论文本。为每条发言保存唯一标识、时间、来源类型、原内容链接、上下文、作者 UID 和采集来源。
5. 过滤其他人的发言，特别区分用户自己的一级评论、二级回复、原创动态和转发内容。无法确认作者归属时标记为待核实，不能猜测。
6. 生成 raw.jsonl、comments.csv 和 manifest.json。manifest 记录来源、采集时间、成功与失败页数、覆盖时间范围、重复数、缺失项以及数据限制。
7. 后续再补充视频标题、简介、字幕片段和评论对话上下文。缺失的信息留空，并标注 context_missing，不得编造。
8. 先输出 20 条脱敏预览和数据质量报告，等待用户检查数据结构后，再批量整理其余数据。当前阶段不生成和发布评论。
9. 仅在用户本人设备与授权账号环境内使用必要权限。不得要求用户把完整登录 Cookie、SESSDATA 或密码粘贴到聊天中；凭证应留在本地安全配置中。
