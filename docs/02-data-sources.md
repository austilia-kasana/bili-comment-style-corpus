# 02 · 数据源与工具

## 实际使用的接口

| 来源 | 端点 | 读什么 | 覆盖 / 限制 |
|---|---|---|---|
| 空间动态 | `x/polymer/web-dynamic/v1/feed/space`（WBI 签名 + 登录态） | 公开动态：原创文字/图文/转发/视频分享，含正文与关联视频卡 | 12 条/页；游标翻页；删除/私密/仅粉丝不可见 |
| 视频评论 | `x/v2/reply`（逐视频分页） | 某视频下的一级评论，按 mid 过滤 | **无全量“我的评论”接口**；只能扫已知视频；每视频最多 30 页 |
| 楼中楼 | `x/v2/reply/reply` | 某根评论下的二级回复 | 需已知 root rpid；用于补 parent/回复对象 |
| 视频元信息 | `x/web-interface/view` | 标题、简介、分区、UP、统计 | 公开可用；本次只对选中的 18+20 个视频定向补 |
| 字幕 | `x/player/wbi/v2` + 字幕 CDN | 官方/AI 字幕轨道 | 需登录 + WBI；不是所有视频都有 |
| 收件箱 | `x/msgfeed/reply` / `at` / `like` | **别人对当前账号**的回复/@/赞 | 是入站消息，不是目标用户的历史发言 |

## 明确不可得

- **全量历史评论**：B 站没有公开接口能列出“某用户在所有视频下的评论”。
- **观看历史 / 点赞记录**：属于私密数据，当前授权账号无权读取；没有尝试绕过。
- **公开收藏夹**：`x/v3/fav/folder/created/list` 返回 -400，未取得收藏视频。

## 工具盘点（DSH 插件）

| 工具 | 读/写 | 用途 | 备注 |
|---|---|---|---|
| `session` / `deps` | 读 | 登录态、ffmpeg、Node、数据目录 | 写操作前先跑 |
| `dynamic list` | 读 | 旧版空间动态 | **实测返回 HTML，被拦**；改用 polymer 接口 |
| `comment-digest` | 读 | 回复我的 / @我的 | 入站消息，不是本人历史评论 |
| `likes` | 读 | 收到的赞 | 入站通知 |
| `thread` | 读 | 某根评论的楼中楼 | 补上下文 |
| `debrief` / `video-content` / `subtitles` | 读 | 视频元信息/字幕/弹幕/热评 | 用于补语境 |
| `comment` / `dynamic` / `dm` | 写 | 发评论/动态/私信 | **本轮测试完全没有调用** |

## 限流与失败处理

- 每页之间 sleep 1.2–1.8 秒；遇到非 JSON、`code != 0`、验证码/限流即停止对应任务，记录失败原因，不绕过。
- 动态游标存 `space_state.json`；评论进度存 `comment_state.json`；楼中楼进度存 `thread_state.json`。
- 所有凭证只在本地 `~/.bili-ai/credentials.json`，不进仓库、不出现在报告里。
