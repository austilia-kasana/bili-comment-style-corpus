# 06 · 任务 04：A/B 盲评

## 设计

| 项 | 设置 |
|---|---|
| 视频数 | 20 |
| 主题 | 游戏 4 · 动物 4 · 搞笑 3 · 音乐 3 · 剧情 3 · 知识 3 |
| 语境质量 | high 10 · medium 5 · low 5 |
| 生成 | 15 组（A/B 各一条） |
| SKIP | 5 个（只有标题/简介无内容） |
| A 组 | 中性基础提示词：“普通 B 站用户，看完视频写一条评论” |
| B 组 | 同一基础提示词 + `data/style_guide_v1.md` |
| 模型 | 同一模型（deepseek-v4-pro） |
| 参数 | 会话内生成，未暴露 temperature/top_p；A/B 上下文相同 |
| 发布 | 无 |

## 上下文与 SKIP

每个视频提供：标题、简介、实际可获得的字幕/正文片段；另列 `known_facts`（已知）与 `unconfirmed`（未确认）。

5 个 SKIP 都是“只有标题 + 制作名单/免责声明/空简介”，硬写只能复述标题或编造：

- 鸣潮爱弥斯 vs 原神兹白（简介为“-”）
- 肥鱼贪吃被制裁（简介只有形象来源）
- 抽象圣体巅峰争霸赛（简介 6 字）
- 现充领导清洗二刺猿 01（简介只有免责声明）
- 花火户型（简介是制作人员名单）

## 产出

- `test_results.csv`：20 行；字段 `video_id, url, topic, context_quality, baseline_comment, personalized_comment, skip_reason, title, context_summary, known_facts, unconfirmed`。
- `blind_review.md`：X/Y 逐条随机，附评分维度。
- `data/blind_key.csv`：X/Y 对应关系（评完再看）。

## 评分维度（用户评）

1. 像用户（语气/句式/用词）
2. 贴合视频
3. 有实际内容
4. 不公式化
5. 事实错误或不恰当立场
6. 偏好：X / Y / 都不行 / 都SKIP

## 结果（用户已填，2026-10-22）

15 组生成、5 个 SKIP。均值：

| 维度 | A 基础 | B v1 |
|---|---|---|
| 像用户 | 1.20 | 1.73 |
| 贴合视频 | 3.00 | 3.40 |
| 有实际内容 | 1.13 | 2.27 |
| 不公式化 | 1.00 | 1.73 |

- 逐条总分：B 赢 12 · A 赢 1 · 平 2。
- 偏好：选 B 3 · 选 A 0 · **“都不行” 12**。
- 事实/立场问题：B 5 条 · A 0 条。
- SKIP：5 个。

**解读**：v1 比模板好，但 12/15 仍然“都不行”；“像用户”只有 1.73/5。这直接推动了 Task 05 的 v2：先把“像本人”做好，再谈准确与不公式化。

## 备注

- A/B 都使用中性基座，没有叠加大肥鱼人格；这是为了隔离“风格指南”一个变量。
- B 组没有搬运历史语料里的事实、立场或个人经历；只使用当前视频上下文。
