# 08 · 任务 05 计划：风格指南 v2 与三组盲测

## 起点与限制

- 任务 05 要求“基于 Task 04 的实际盲评结果”。**目前没有收到用户对 Task 04 的 1–5 分或偏好**，因此本文件不声称“基于评分”。
- 本轮依据的是用户在任务 05 中**明确指出的三个问题**：
  1. 《贫民窟的百万富翁》的镜子字母 B；
  2. 《司凤小猫》的动作信号；
  3. 音乐视频的实际主题。
- 不覆盖 Task 04 原始产出；v1 指南原文保留。

## 一、上下文审计（12 个视频）

- 每条可用于生成的事实都标注来源：`video_visual` / `subtitle` / `description` / `title` / `inference`。
- 严格区分“简介写了什么”和“视频实际展示了什么”；只有简介依据的标 `description_only`。
- 三个重点核验：
  - **镜子 B**：字幕只证明主持人写了 B、贾马尔最后选了 D；动机（帮忙/设套）无依据 → `needs_review`。
  - **司凤小猫**：字幕同时讲了面部信号（眼睛）和肢体动作（内收/外扩）；Task 04 只提眼睛 → 补动作。
  - **音乐**：19sp 的歌词是实际内容；简介里的“绿色DJ版”是描述，不是已核验的音频；Task 04 的“跟着哼”是虚构个人体验 → v2 禁止。
- 矛盾/不明事实先标 `needs_review`，不擅自选一个当事实；本轮把《百万富翁》的动机列为 needs_review，但生成时只使用已确认事实（不再写动机）。

## 二、v2 硬性规则

见 `data/style_guide_v2.md`：具体≠准确、不推断动机、不编造个人体验、不强制金句、先考虑直接反应、五个目标不能互相替代、不足就 SKIP。

## 三、三组盲测

- 从上下文已核验的视频中选 **12 个**，覆盖游戏 2、动物 3、搞笑 2、音乐 1、剧情 2、知识 2。
- 同一模型、同一上下文、同一输出约束：
  - A：基础提示词
  - B：基础 + v1
  - C：基础 + v2
- 每组只差风格指南；不发布。
- X/Y/Z 逐条随机，盲评表不暴露版本；映射单独存 key。

## 四、指标

- 保留：像本人、贴合视频、有实际内容、不公式化（1–5）。
- 新增：是否愿意直接发出去（是/否）；是否存在事实错误、虚构个人体验或不符合本人立场（无/有 + 原因）。
- 事实/立场问题单独统计，不用其他维度高分抵消。

## 五、非目标

- 不宣布哪组更好（用户盲评前）。
- 不把 v2 当最终人格规则。
- 不发布、不扩大采集、不读私密数据。
